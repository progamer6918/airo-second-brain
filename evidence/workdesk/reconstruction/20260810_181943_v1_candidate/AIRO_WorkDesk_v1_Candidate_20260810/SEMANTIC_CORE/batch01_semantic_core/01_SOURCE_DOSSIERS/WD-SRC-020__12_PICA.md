## Purpose

This is not merely a PICA template. It teaches how to move from a broad performance symptom to a specific, evidence-supported problem and then to a corrective action. It provides two analysis paths:

- **Area → Product**
- **Product → Area**

and two main application examples:

- PICA for **Retail Sales**.
- PICA for **Market Share**.

The source's strongest lesson is epistemic: a plausible explanation is not enough. A “good” PICA must identify a root cause that actually explains the observed change and then design corrective action against that cause.

## Conceptual core

`PICA = Problem Identification & Corrective Action`

The source visualizes Problem Identification as a funnel from **UMUM → KHUSUS**. The analyst narrows from aggregate performance to the contributor and then to causal evidence.

5. Breaks further to types with negative growth.

### Slide 17 — Retail Sales problem statement
Question: **Why did Daily Sales Retail (SSU) decline?**

### Slide 18 — Step 1: establish analysis basis
The source says daily-sales growth analysis can be based on:

- Market info: commodity prices, weather, natural disaster, political issue, etc.
- Competitor info: sales program, stock level, promotion, BTL, GC, etc.
- Honda stock / SMH: e.g. short stock on certain types, GC realization.
- Honda info: sales-program changes, BTL changes, etc.

This list is a **candidate evidence set**, not permission to claim any item is causal without validation.

### Slide 19 — Step 2: segment contribution
Check which segment declines or is anomalous relative to All Type. The source explicitly says an increasing segment can also deserve analysis if it is anomalous. This is important: PICA is about explaining deviations, not only negative values.

### Slides 20–22 — Step 3: series-level analysis
For the contributing segment, identify the series contributing most to the change and analyze source-stated factor families:

- Competitor program / stock / promotion / BTL / GC.
- Honda stock / short stock / GC realization.
- Honda sales program / activity changes.

Sport example explicitly asks additional questions such as whether there was GC, prior short stock causing current fulfillment, new Honda programs, or competitor changes.

### Slide 23 — Bad PICA example
Question: how to explain CB150R daily-sales decline (`-8.4%`)?

The “bad” analysis lists facts such as continuing programs, commodity-price decline, and lower GC. The source explicitly criticizes it because it does not answer the problem:

- If the program continued, why did CB150R still decline?
- What changed from last month?
- Why had Honda not countered?
- Why would commodity decline affect CB150R but not other series?
- If GC is claimed, how many units and can it actually explain the magnitude?

This is one of the strongest diagnostic-quality gates in the corpus so far: **candidate facts must explain the differential outcome and magnitude**.

### Slide 24 — Good PICA example
The improved analysis identifies a competitor intervention:

- Yamaha `Vixion September Ceria` with additional discount, changing discount/DP Real.
- Yamaha `RO-TI Program DP=0` starting September.

The slide says this root-cause analysis can explain why CB150R sales declined and that the next step is a Honda corrective/counter action.

### Slide 25 — Corrective-action example
Problem Identification from September competitor programs is translated into October counteractions, including a CB150R discount/direct-gift change and a segmented fixed-income program with changed tenor/DP parameters.

Important semantic rule: corrective action is linked to the identified competitive mechanism, rather than being a generic activity list.

## Procedural memory — source-grounded PICA sequence

### Generic decomposition

1. Start from a measurable performance symptom.
2. Ensure dashboard granularity reaches Dealer and series/type.
3. Choose decomposition direction:
   - Area → Product, or
   - Product → Area.
4. Narrow general performance to the major contributor(s).
5. Continue to lower granularity until the specific problem location/product is isolated.
6. Gather candidate evidence: market, competitor, Honda stock, Honda programs/activities, and other source-stated factors.
7. Test whether the proposed explanation actually accounts for the observed change.
8. Reject explanations that are merely correlated/plausible but do not explain differential behavior or magnitude.
9. Form Problem Identification/root cause.
10. Design Corrective Action against the identified mechanism.
11. Define next action and execution focus.

### Retail Sales path

`All Type daily-sales symptom → segment anomaly/contribution → series contribution → evidence / causal test → PI → CA`.

### Market Share path

`Total M/S symptom → Pareto subsegment contribution + declining M/S → subsegment analysis → situational analysis → PI → CA → next action`.

## Diagnostic principles

1. **Localization before explanation.** Find where the performance contribution sits before asserting a cause.
2. **Anomaly can be positive or negative.** A segment growing contrary to total movement may also need explanation.
3. **Causality needs contrast.** If a commodity decline is claimed to explain CB150R, ask why comparable series did not behave similarly.
4. **Magnitude matters.** If GC is claimed, quantify whether it can explain the observed sales change.
5. **Change matters more than existence.** A program that existed both periods cannot by itself explain a new decline unless something material changed.
6. **Corrective action must address the identified mechanism.** Generic activities without causal linkage are weak PICA.

## Case memory — CB150R “good vs bad” PICA

### Problem
CB150R daily sales down 8.4% in the worked historical example.

### Weak analysis pattern
Lists ongoing programs and broad external factors without demonstrating why the decline occurred now or why CB150R was affected differently.

### Quality questions from source

- What changed vs prior month?
- Why did continued programs fail?
- Why no counter action?
- Why did the claimed market factor not similarly affect related models?
- Can the cited GC volume explain the magnitude?

### Stronger root cause
A materially changed competitor price/program proposition (additional discount, lower DP / DP=0 program) is used to explain the competitive loss.

### Corrective action
Honda counter-program changes targeting price/DP/segment, linked to the identified competitor mechanism.

### Reusability
The specific program values are historical examples. The reusable pattern is **before/after competitor proposition → affected model → causal comparison → targeted countermeasure**.

## Unresolved / do-not-invent register

1. The deck does not define a formal statistical causality test; its causal quality is evaluated through contribution, change, contrast, and magnitude reasoning.
2. `GC`, `SMH`, `RO-TI`, and some historical program labels are not expanded in this source; glossary resolution must use other sources or owner evidence.
3. Historic example values must never be presented as current price/program rules.
4. The source does not say every PICA must always use every factor family; factor selection depends on the symptom.
