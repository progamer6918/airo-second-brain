# Playbook: New Project from Skill Source

## Goal

Turn an external GitHub repo into a reusable AI skill or project idea.

## Steps

1. Star or fork the source repo.
2. Read the README.
3. Identify the core pattern.
4. Convert the pattern into a skill card.
5. Create a small project template.
6. Test the skill on one real use case.
7. Record lessons learned.

## Do Not

- Copy huge repos blindly.
- Mix unrelated code into active projects.
- Run install scripts without inspection.
- Commit tokens or credentials.
