# Google Workspace Integration Plan

## Account Model

Use a dedicated Airo Google account.

The user's main Google account shares selected files/folders manually to Airo.

## Recommended Google Workspace Folder

Airo Personal Workspace/
- Ledger Sheets/
- Receipts/
- Monthly Reports/
- Attachments/
- Exports/

## Phase 1

- Sheets export
- Drive upload
- Docs report draft

## Phase 2

- Calendar reminders

## Phase 3

- Gmail limited workflow, if really needed

## Important

Do not paste OAuth client secret, token, refresh token, cookie, or session into chat.
