# Airo Personal Workflow Safety Policy

## Allowed Automatically

- Add clear new transactions
- Add clear payment records
- Upload receipt files into Airo-only Drive folder
- Export database summary to Airo-owned Google Sheets
- Generate monthly report drafts
- Notify user about changes

## Audit Required

- Update paid/unpaid status
- Change category
- Change billing cycle
- Change due date
- Merge duplicate transactions
- Reconcile transactions with evidence

## Confirmation Required

- Conflicting amount
- Conflicting date
- Conflicting payment status
- Missing evidence for important payment
- Editing old financial records
- Calendar creation for unclear due date

## Blocked

- Passwords
- OTP
- Browser cookies
- Session export
- Full Drive access
- Internet banking
- Credit card portal login
- Financial payment execution
- Live trading
- Hard delete financial records

## Delete Policy

No hard delete.

Use soft delete:
- deleted_at
- deleted_reason
- deleted_by
