# Skill: Build-Your-Own Project Planner

## Use When

Use this skill when the user wants to learn a technology by building a simplified version from scratch.

## Core Idea

Do not only install tools. Understand systems by building small working versions.

## Output Pattern

1. Minimal concept
2. Smallest working version
3. Component map
4. Build steps
5. Test command
6. Debug checklist
7. Extension ideas

## Example Applications

- Build your own backtesting engine
- Build your own trading journal
- Build your own Telegram control bot
- Build your own paper exchange simulator
- Build your own knowledge base indexer
