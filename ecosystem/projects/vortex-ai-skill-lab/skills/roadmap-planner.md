# Skill: Roadmap Planner

## Use When

Use this skill when the user wants to learn a domain, plan a project, or decide what to build next.

## Output Pattern

1. Current level
2. Target outcome
3. Required skills
4. 30-day roadmap
5. 60-day roadmap
6. 90-day roadmap
7. Projects to build
8. Validation checklist
9. Risks and shortcuts to avoid
