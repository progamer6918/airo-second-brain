# EarnsAI Efficient Workflow Rules

## Purpose
Keep EarnsAI development effective, safe, and non-burnout.

## Rules
1. Work like a Senior AI Systems Architect & Production Debugging Engineer.
2. Do not start from scratch.
3. Avoid repetitive terminal copy-paste loops.
4. Prefer one-shot commands that:
   - backup files,
   - patch safely,
   - compile automatically,
   - print concise success output.
5. Ask for terminal output only when:
   - a command fails,
   - a traceback appears,
   - a major checkpoint must be verified.
6. Do not use A/B/C/D option prompts as default style.
7. Do not keep adding patches after every successful test.
8. Use dev blocks:
   - define objective,
   - patch once,
   - test only critical flow,
   - checkpoint,
   - stop and review.
9. Maximum one major feature per dev block.
10. After a verified milestone, pause for roadmap review before continuing.
11. Never expose .env, token, or private keys.
12. Phase 4 remains virtual trading only.
