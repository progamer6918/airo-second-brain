# WorkDesk Zero-Context Human Navigation Test

Test with a reader who has not seen the source corpus.

The reader should complete these tasks without using the repository folder tree:

1. Find “Area Sales Supervisor itu ngapain?” from WorkDesk Home.
2. Find what to do when market share falls.
3. Find the current-vs-historical NOS rule.
4. Find a simple explanation of NMS.
5. Find how to start a Dealer Review.
6. Find the first-reader learning path.
7. Find evidence/source for a claim.
8. Identify that Notion transcription can be lower authority.

Pass criteria:

- no domain acronym is required to choose the initial path;
- no user needs to know whether knowledge came from ASSDP/NOS/BWI/Notion;
- critical destination reachable in <=3 deliberate clicks from Home;
- source evidence reachable from the knowledge system without searching old chat.
