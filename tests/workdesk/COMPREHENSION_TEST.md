# WorkDesk Fresh-AI Comprehension Benchmark

A fresh AI that passed WorkDesk boot should answer these without relying on old chat.

## Critical cases

1. **Role:** Explain why ASS is not merely a sales supervisor. Must include market/target/dealer/execution/control dimensions.
2. **Market Share:** MS falls. Must not jump directly to promo; must validate denominator/scope and drill market/segment/area/dealer/competitor/execution.
3. **Dealer Review:** Explain why it is a management diary, not visit decoration.
4. **Targeting:** Explain market → kabupaten → dealer → people/activity breakdown.
5. **Demand:** Explain how forecast/sales plan/supply/stock connect.
6. **Stock:** Explain MD → kabupaten → dealer → series monitoring hierarchy.
7. **Pricing:** Explain why DP/discount/installment/fincoy competitiveness matter beyond OTR.
8. **NOS authority:** 2023 and 2026 conflict. Must choose current 2026 for current standard.
9. **NOS applicability:** Must identify network type before applying checklist.
10. **NOS scoring:** Must reject naïve average-only logic without checking applicability/N-A/mandatory/current workbook.
11. **NMS:** Must know the owner-confirmed name but avoid inventing a full module map.
12. **MyHero:** Must separate historical feature evidence from current runtime; self-audit NOS ≠ official audit result.
13. **Notion conflict:** Formal material beats noisy transcript unless stronger current evidence exists.
14. **AT High:** Must connect market/competitor/dealer/customer/activity, not treat it only as a product target.
15. **Owner project:** Must identify DMAIC in Advanced project without treating 2026 case numbers as current truth.
16. **Leadership:** Must explain why influence/coaching/change is a business-execution capability, not a decorative soft skill.
17. **PICA:** Must distinguish symptom/generic explanation from causal problem identification.
18. **Activity low result:** Must inspect funnel/targeting/frequency/quality/people/stock/financing before declaring BTL ineffective.
19. **Evidence:** Must be able to name source authority class and source ID for an important claim when asked.
20. **Completion honesty:** Must state that 106/106 accounted does not mean 100% semantic/visual digestion.

## Pass rule

Critical tests 1–20 must pass on the canonical build before `FULLY_DIGESTED_AND_TRANSFERABLE=YES` can be considered.
