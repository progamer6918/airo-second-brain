1. Current NOS rule: use current 2026 official source over 2023 historical material.
2. Theory taught by BWI: use relevant BWI material as primary description of that theory.
3. Owner working pattern: use current work evidence and Owner-confirmed context; use applied projects as supporting historical evidence.
4. Presenter note conflicts with formal slide: formal slide wins unless a newer verified update exists.
5. Public web conflicts with current internal source: current internal/owner-confirmed source wins for the local operating context.
6. Model memory conflicts with repository/source evidence: repository/source evidence wins.
