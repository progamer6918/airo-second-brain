# 📥 SOP & Panduan Pembaruan Data & Pengetahuan AIRO

## 1. Prinsip Utama
Materi dapat dipelajari dari perangkat kerja mana pun. Jika workspace utama belum diperbarui, status **Siap Diterapkan**. Penerapan dilakukan pada workspace utama yang sudah diperiksa, terlepas dari perangkat.

## 2. Alur Kerja Pembaruan Bagi Owner
1. **Unduh / Simpan File**: Masukkan file data/dokumen baru ke folder `AIRO_HANDOFF/00_DROP/`.
2. **Selesai**: AIRO akan secara otomatis mengklasifikasikan, memproses, merekonsiliasi, dan memperbarui memori WorkDesk.

## 3. Status Siklus Pembaruan
- **Sedang Dipelajari**: AIRO sedang menganalisis file intake baru.
- **Siap Diterapkan**: Rekonsiliasi selesai, menunggu konfirmasi/persetujuan Owner.
- **Sudah Diperbarui**: Data/dokumen telah tersimpan permanen di memori WorkDesk.
- **Perlu Klarifikasi**: Terdapat benturan data yang membutuhkan keputusan Owner.
- **Duplikat**: Data sudah ada sebelumnya.
- **Ditunda**: Diarsipkan untuk pemrosesan berikutnya.
