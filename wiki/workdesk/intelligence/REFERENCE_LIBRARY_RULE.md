# 📚 Reference Library Treatment Rules

## Rules
1. **ASSDP & Methodological Guides**: Treated strictly as reference materials (`REFERENCE_ONLY`).
2. **No Fact Promotion**: Training slides or workshop cases must never be promoted to live operational facts.
3. **Separation**: Reference frameworks assist diagnostic reasoning but do not override baseline facts.
