# Cara Membaca WorkDesk

WorkDesk melayani pembaca nol-konteks tanpa memaksa semua orang mengikuti kurikulum penuh.

## 1. Casual reader — default

Punya kebutuhan sekarang? Mulai dari Home → pilih **Cari**, **Selesaikan**, atau **Bikin**.

Pola: `gejala/niat → penjelasan singkat → langkah kerja → detail hanya bila perlu`.

## 2. First reader

Mau benar-benar mengerti dunia kerjanya? Gunakan [[START_HERE]].

Pola: `ecosystem → role → market/dealer → sales/network → analysis → strategy/execution`.

## 3. Practitioner

Langsung masuk ke knowledge module atau playbook. Setiap note mengutamakan keputusan dan cara pakai.

## 4. Auditor / expert

Turun ke evidence: source ID, lokasi, authority, uncertainty, conflict register dan raw source pointer.

## Progressive depth

- **10 detik** — apa ini.
- **Buat kerja** — kenapa penting dan apa yang dilakukan.
- **Mendalam** — logic/framework/exception.
- **Evidence** — sumber dan tingkat keyakinan.

User tidak perlu tahu struktur repository untuk mulai bekerja.
