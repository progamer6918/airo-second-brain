# 🛠 Bikin Output Kerja

Pilih output berdasarkan kebutuhan, bukan berdasarkan file source.

## Output types

- Dealer Review
- PICA / corrective-action plan
- Business Case
- Market/Area Insight
- Excel analysis
- Power BI analysis/story
- Presentation
- Meeting preparation
- Dealer/leader communication

Each output module will be added during M3 compilation.

## Current rule

Before producing a polished artifact, validate:

1. problem/objective;
2. data/source scope;
3. business logic;
4. current-vs-historical status;
5. expected audience/action.

Do not beautify an unvalidated conclusion.
