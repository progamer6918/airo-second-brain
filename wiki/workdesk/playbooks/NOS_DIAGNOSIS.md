# Playbook — NOS Diagnosis

1. Resolve network type first.
2. Use the current 2026 workbook for that network.
3. Resolve H1/H23 and Premises/Process/People.
4. Locate the exact indicator and mandatory/layer status.
5. Verify actual condition/evidence; evaluate N/A only by current rule.
6. Separate symptom from operational root cause.
7. Build PI → CA/PICA → PIC/timing/evidence.
8. Recheck current result/mandatory gate after correction.

Historical 2023 materials may help explain why/visual example, but 2026 current standard wins on conflicts.
