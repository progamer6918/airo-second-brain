# Private WorkDesk Sidecar Contract - Public Pointer

AIRO Second Brain is public. Sensitive operational business memory must not be copied into public ASB merely because it improves analysis.

## Private by default

- actual dealer identities/performance where commercially sensitive;
- market/retail granular data;
- stock current values;
- monthly commercial-program/MSW amounts;
- customer transaction data and PII;
- financing/approval details;
- internal claim/process evidence;
- case evidence not explicitly cleared for public storage.

## Public ASB retains

- analytical frameworks;
- safe diagnostic/playbook logic;
- data contracts/schemas without sensitive values;
- currentness and source-authority rules;
- sanitized examples;
- safe pointers to private dataset classes.

## Retrieval expectation

A WorkDesk-capable AI may use the private sidecar when connected/available. If it is not available, it must state the missing data rather than fabricate it.
