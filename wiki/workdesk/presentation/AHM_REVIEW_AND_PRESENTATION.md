# AHM/MD Review & Presentation Logic

## 🍼 10 detik

Presentation bukan dekorasi. Untuk WorkDesk, deck yang bagus harus membawa audiens dari **context → evidence → diagnosis → implication → action/control**.

## AHM/MD review reference

The 2026 ND Plan/Reshape deck is a strong reference for:

- management-review content architecture;
- data-heavy slide patterns;
- market/economic → H1/H2/H3/HC3/Dev → area/network → PICA → Reshape storyline;
- visual patterns such as KPI tables, quadrants, mapping, roadmaps and PICA.

## BWI presentation principles

Basic BWI teaches purpose, readiness, audience, clarity, voice, interest, body language, enthusiasm and storytelling; it also uses openings/attention grabbers and strong ending/mood control.

## WorkDesk presentation workflow

1. Define audience and decision/ask.
2. Select only evidence needed for that decision.
3. Build storyline before formatting.
4. Separate fact, inference and recommendation.
5. Make title/conclusion carry the message.
6. Use AHM visual structure when the context requires it; creative mode may differ.
7. Validate all numbers before presentation.
