# INS — Integrated Network Sustainability (Historical 2023 Framework)

## 🍼 10 detik

INS adalah framework untuk melihat apakah jaringan **perform, competitive dan sustainable**, bukan hanya apakah sales-nya tinggi.

## Historical model in ASSDP 2023

The material combines several lenses:

- quantitative performance & potential (INM);
- qualitative network condition/early warning (INQE);
- NOS standardization/customer perspective;
- customer-satisfaction indicators;
- smart/digital network implementation.

It spans H1/H2/H3/HC3 and includes people, financial condition, infrastructure, CRM, stock/productivity and digital process indicators.

## Development use

Network classification is intended to guide:

- which network to preserve/develop;
- where integrated review should focus;
- coaching/counseling/PICA;
- progress monitoring;
- cross-functional alignment;
- target and development discussion with dealer leadership.
