# Problem-Solving System — RCA, PDCA, PICA, DMAIC & Business Case

## 🍼 10 detik

Framework bukan hiasan. Pilih sesuai jenis masalah, lalu pastikan problem → root cause → action → control tetap tersambung.

## RCA

`Problem statement → hypotheses/symptoms → repeated why/root cause → solution + PIC + deadline + status`.

Use when the core need is to isolate causal drivers.

## PDCA

ASSDP applies PDCA directly to the ASS role:

- **Plan:** forecast/target/strategy/supervision plan.
- **Do:** sales/stock monitoring, execution, field supervision, coordination.
- **Check:** economic/market evaluation, target/share, Dealer Review.
- **Action:** PICA, dealer correction, new strategy/activity/program.

Use for recurring management/control loops.

## PICA

Problem Identification should move from general to specific through a route of analysis. For Retail Sales and Market Share, drill into contribution/segment/series/area/dealer and require explanation specific enough to justify a corrective action. Generic statements such as “commodity down” or “competitor program continues” are insufficient if they do not explain the measured change.

## DMAIC

Owner Advanced project uses:

`Define → Measure → Analyze → Improve → Control`

Use for a structured improvement project requiring baseline, quantified gap, root cause, integrated intervention and control.

## Business Case

Intermediate curriculum treats Business Case as a way to convert diagnosis into an evidence-backed recommendation/decision. Exact workbook template is structurally extracted but still pending full semantic audit.
