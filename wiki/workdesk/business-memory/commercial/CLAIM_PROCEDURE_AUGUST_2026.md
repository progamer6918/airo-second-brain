# Claim Procedure August 2026 - Private Semantic Digest

**Source File:** `059 - Juklak Tata Cara Klaim Periode Agustus 2026.pdf`  
**Visual inspection:** pages 1-4 completed for candidate build.

## Systems / route

- S.E.E.D.S is used for claim data across program categories.
- Sales Support is described as running through auto claim, so Sales Support does not require PIM input.
- PIM is required for the Special Gift jacket program (BeAT Sporty series and New Vario 160 Evo series).

## Claim cadence
Dealer is required to input claims daily and upload complete/clear supporting requirements. Weekly maximum input deadlines are defined as:

| Sales period | Max input |
|---|---|
| 1-7 Aug | 9 Aug 2026 |
| 8-14 Aug | 16 Aug 2026 |
| 15-21 Aug | 23 Aug 2026 |
| 22-27 Aug | 29 Aug 2026 |
| 28-31 Aug | 2 Sep 2026 |

Main Dealer monitoring is scheduled after each corresponding sales window.

## Missing / late evidence

- If a sale does not claim/join an applicable program, Dealer must send the specified confirmation explaining why.
- If a requirement cannot yet be uploaded within the weekly deadline (for example Special Gift handover evidence), Dealer must send the specified missing-requirement information and commitment date.
- Missing S.E.E.D.S/PIM input or late input causes the claim to be declared forfeited; program contribution becomes Dealer responsibility under the source.
- Main Dealer approves against valid input/uploads.
- Manual Dealer claim processing is not accepted.
- Original claim documents must be retained completely for five years.

## Sales Support claim evidence

Source requires the applicable-period:

- Sales Invoice;
- Vehicle BAST;
- Finco PO for credit;
- DP Setor receipt for credit or settlement receipt for cash.

## Special Gift claim evidence

Includes applicable-period invoice/BAST/Finco PO plus Special Gift handover BAST, handover photo, and identity evidence. If the recipient is an eligible immediate-family representative, family relationship evidence is required. PII from these materials must never enter public ASB.

## Data/document consistency rules

- Upload file naming uses Dealer/POS code + engine number + evidence type.
- Invoice must show the total sales-support amount including PPN as required by the source.
- DP-setor receipt amount must reflect the support deducted from the customer payment.
- Receipt print date may be earlier than SSU but not later than SSU under the source example/rule.
- Use the current-period form and correct program ID.
- Invoice/PO/BAST periods must match the active program period.
- Claim portal data must match uploaded evidence.

## Rejection examples explicitly stated

Examples include incorrect support amount/PPN, support below Juklak, receipt date after SSU, missing original receipt to customer, no/incorrect Sales ID Program, or period mismatch.

## One-program rule

Each unit can normally join only one program (no double claim), with an explicit August exception allowing the BeAT Sporty Special Gift program to run together with the BeAT Sporty / BeAT Sporty MMC Sales Support specified in Juklak 056.

## Currentness
All deadlines and program combinations are August 2026 operational facts only.
