# AIRO WorkDesk Private Sidecar Candidate

**PRIVATE - DO NOT COMMIT TO PUBLIC ASB.**

This sidecar holds business-memory metadata and private operational knowledge that should be usable by WorkDesk without being published.

Raw source files are not duplicated into this candidate package. The registry records provenance/hashes so the Owner can keep using the original private vault/source folders.

PII rule: customer names, NIK/KTP/KK, phone, email, address, signatures, and other personal data are not copied into derived WorkDesk notes unless a specific private case genuinely requires them. Analytics should prefer aggregation/pseudonymization.
