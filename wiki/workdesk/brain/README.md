# AIRO WorkDesk — Canonical Professional Brain Persistence Candidate

This directory is the **professional reasoning memory** candidate produced after the 80-source baseline reconstruction and cross-source reconciliation.

It is not a replacement for the human WorkDesk Home, business-memory plane, current operating data, or raw source evidence. It is the durable semantic layer that a fresh AI should consume so routine professional work does not require re-reading the original training/source corpus.

## Epistemic boundary
- 80/80 physical professional baseline sources were processed.
- Low-90s operational semantic fidelity is supported by the current explicit rubric; this is **not** a word/pixel-copy percentage.
- Dense row-level historical tables, workbook execution parity, fine visual labels and source-bounded missing authority remain explicit limitations.
- `PRACTICALLY_LOSSLESS_BASELINE=NOT_YET_PROVEN` until fresh-AI functional transfer testing passes after persistence.
