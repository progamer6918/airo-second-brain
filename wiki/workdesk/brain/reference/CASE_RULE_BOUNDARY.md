# Case → Rule Boundary

Historical Owner/training cases are part of WorkDesk memory because they preserve how problems were framed, which evidence mattered, what was tried and what happened. They are **not** automatic forecast models. **Cases do not create causal forecasts.**

## Canonical treatment

For every case preserve separately:

1. context / period / area;
2. symptom and baseline;
3. diagnosis / cause hypotheses;
4. intervention;
5. monitoring method;
6. source-reported outcome;
7. unresolved confounders;
8. reusable reasoning pattern;
9. what must **not** be generalized.

## Examples

- **Merangin AT High:** proves the importance of denominator/competitor growth and integrated branding/activity/customer work. It does not prove the same event mix causes the same uplift elsewhere.
- **PENETRASI Merangin:** reusable pattern is paradox → evidence → cause cluster → intervention by cause → control system. Historical M/S results are not a current forecast.
- **Aging stock incentive:** reusable pattern is aging-stock diagnosis + salesperson behavior + targeted intervention + monitoring. Historical incentive amounts and result uplift are not current policy or guaranteed effect.
- **Dealer transformation / Bali / LOL sharing:** preserve patterns and failure/recovery mechanisms; local historical numbers remain context-bound.
