# Source → Brain Traceability Rules

1. A canonical rule must point to an actual source/dossier provenance location or be labeled synthesis/inference.
2. Historical examples remain queryable but cannot silently become current policy.
3. Contradictory source content must remain contradictory until authority resolves it.
4. Duplicate/aggregator sources add provenance, not duplicate knowledge.
5. If a future question requires a dense row/pixel not structured into brain memory, the system should fall back to source evidence rather than fabricate.
6. Fresh-AI transfer is failed if source-grounded meaning exists in reconstruction artifacts but is absent from canonical ASB content.
