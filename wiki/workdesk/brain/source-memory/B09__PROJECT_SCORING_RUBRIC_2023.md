## Weighting
- **Concept - 30%**: issue/challenge fit 10%; causal/root-cause explanation 10%; solution fit 10%.
- **Implementation - 50%**: before/after 10%; systematic/complete implementation 15%; field result 15%; standardization for sustainability 10%.
- **Monitoring - 10%**: monitoring process that keeps the improvement running.
- **Slides & presentation technique - 10%**: slide quality 5%; delivery technique 5%.

## Score bands
The template defines descriptive bands:
- 55-69
- 70-84
- 85-100

The highest band expects the theme and solution to answer the issue, root causes to be developed using problem-solving/decision tools, before/after evidence including at least one implementation example, systematic and creative implementation, sustainable standardization, non-trivial monitoring, and disciplined slide/delivery technique.

## Design implication for WorkDesk
A strong deliverable is not only analytically correct. The rubric rewards the full chain:
**issue -> cause -> solution -> implementation -> result -> standardization -> monitoring -> communication.**
