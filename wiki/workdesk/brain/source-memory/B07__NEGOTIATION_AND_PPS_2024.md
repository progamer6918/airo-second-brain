## Negotiation preparation

The distributive-bargaining section defines four anchors:

1. **BATNA** - Best Alternative to a Negotiated Agreement; the best alternative if the deal does not happen.
2. **Reservation Value** - the lowest value still acceptable; source notes it is usually equal to or better than BATNA.
3. **Aspiration Value** - the desired/ideal value.
4. **ZOPA** - Zone of Possible Agreement; the range in which agreement can occur.

Durable decision rule: know your fallback, walk-away boundary and aspiration before negotiating; do not treat the other party's first offer as the only reference point.

## Practical Problem Solving model

Problem definition:

`Problem = gap between actual condition and desired condition`.

Three problem elements:

`Problem -> Root Cause -> Solution`.

The Practical Problem Solving tool maps to:

### Find the problem point
1. Breakdown & Pareto.
2. Check data.
3. Hypothesis template.
4. Use trackback when the issue follows a process/workflow.

### Analyze root cause
- 5 Whys, applied until a root cause rather than another symptom is found.

### Analyze solution
- Solution template separates **Temporary** and **Real** solution, with PIC, due date and status.

## Laptop-hang case

The case demonstrates the method:

- 20 complaints are broken down by department, laptop and user.
- Pareto isolates the highest complaint concentration to Sales -> Laptop A -> one user (Fatin).
- Hardware checks are OK; OS/program behavior is investigated.
- Data check shows the hang tends to occur while using Microsoft Office rather than monitor display.
- Competing hypotheses are tested; "antivirus not updated" survives while other hypotheses are rejected.
- 5 Whys leads to a root cause: antivirus update is still performed manually.
- Temporary solution: scan the affected laptop.
- Real solution: automate antivirus updating.

This case is valuable because it distinguishes symptom, problem point, hypothesis, root cause, temporary fix and systemic fix.
