## Usable semantic memory

The note warns against treating capacity or technical feature availability as automatically sufficient. Evaluation must also test readiness/competence:

- dedicated team;
- fixed/specific operational place;
- technical knowledge;
- management system;
- technical service support.

This is aligned with the Reshape/Network Transformation theme: a network or system improvement is not valid merely because the facility/tool exists. It must be operationally competent and sustainable.
