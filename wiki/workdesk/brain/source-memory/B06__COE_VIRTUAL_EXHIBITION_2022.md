# Source Dossier - COE Virtual Exhibition 2022

**Source:** `COE VIRTUAL EXHIBITION 2022.pptx`, 1 slide.

The slide is a historical coordination calendar. It shows early 2022 event windows and then a planned monthly mix of Independent and finance-company VE slots (MCF, SOF, ADMF, FIFASTRA, etc.).

Its semantic value is not the exact old dates. It establishes that VE was intended to run as a **planned recurring portfolio of event sources**, not as one undifferentiated monthly campaign.

This supports the lead-source rule in the 2022 guidance: each event/source needs distinct coding so performance by platform/finance-company can be evaluated.
