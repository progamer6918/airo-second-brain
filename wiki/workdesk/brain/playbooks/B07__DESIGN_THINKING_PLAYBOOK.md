# Design Thinking Playbook

Use when you still need to discover the right customer solution.

1. **Explore:** immerse, observe, engage. Ask What / How / Why.
2. **Identify:** synthesize User / Need / Insight with empathy evidence.
3. **Ideate:** write HMW; generate many options before filtering.
4. **Visualize:** build the simplest prototype that can create a real user experience.
5. **Evaluate:** let users interact; observe; ask what worked and what remains unmet.
6. **Loop:** go backward when evidence invalidates the current idea.

Do not confuse a pretty concept slide with a tested solution.
