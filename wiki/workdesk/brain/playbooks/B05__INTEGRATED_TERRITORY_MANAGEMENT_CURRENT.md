# Integrated Territory Management — Current 2026

## Use this when
Use for current Network Development territory questions involving dealer/network, kecamatan, POS, Ring, H1/H2 coverage, activity planning, or ND Plan Review.

## Current model
Integrated TTM is the 2026 evolution of older H1-focused TTM. Dealer/network remains the management base; analysis expands through area/kabupaten/kecamatan and POS and integrates H1 + H2.

## Step 1 — Mapping Ring
1. Start from target families: M/S, Sales, UE, SPR.
2. Break down to area → kabupaten → kecamatan → network/POS.
3. Load H1 Data Registration and H2 Customer Movement.
4. Map 100% network/POS locations for coverage.
5. Determine potential by:
   - Market Growth H1
   - Loss Demand H2
   - existing coverage condition
6. Derive priority mapping + coverage strategy.
7. Set coverage plan and final target.

### POS scope rule
Do not confuse:
- **coverage mapping:** all POS
- **2026 performance/target input:** Mega POS + Selected POS according to the target mechanism

For SSP, supplied meeting target = 3 Mega POS / 0 Selected. The current Sinsen working sheet does not yet contain POS class, so exact selection is unresolved from that sheet alone.

## Step 2 — Activities & Scheduling
Translate coverage plan into:
- H1/H2 activity
- location
- schedule
- manpower/salespeople/mechanics
- target
- cost
- joint activity where relevant

Check manpower adequacy before blaming execution.

## Step 3 — Review & Monitoring
Quarterly:
1. review kabupaten and mapping coverage;
2. slice to kecamatan and network/POS;
3. input actual H1/H2 performance;
4. inspect cross-border/customer movement;
5. inspect manpower and executed activities;
6. define PICA only after problem point is localized;
7. monitor improvement through ND Plan Review.

## 2026 KPI / monitoring
- Achievement Lokasi ≥85%
- Achievement Ring 1 ≥85%
- Locality based on grading
- SSP Target Locality 2026 = 89%
- H2 is integrated for analysis/monitoring, but current meeting says 2026 KPI remains H1-focused.

## POS master-data quality gate
Before using POS in Integrated TTM:
- validate count;
- remove duplicates;
- reconcile H1/H2/H23 identity;
- assign standardized code;
- complete type/class/location/coordinates;
- preserve closed/relocated/reopened code lifecycle;
- do not treat TEFA/POS-SMK as POS when source classifies it as TEFA.
