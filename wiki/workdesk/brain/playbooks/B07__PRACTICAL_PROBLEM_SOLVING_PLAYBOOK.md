# Practical Problem Solving Playbook

## 1. State the gap
Actual vs desired, with magnitude and time period.

## 2. Find the problem point
- Breakdown/Pareto.
- Trackback if there is a workflow.
- Check facts/data.
- Write competing hypotheses.

## 3. Test hypotheses
For each: expected condition, actual condition, evidence, OK/NOK.

## 4. 5 Whys
Keep asking why until the answer is a controllable root cause rather than another symptom.

## 5. Solutions
Separate:
- Temporary containment.
- Real/systemic correction.

For each: PIC, due date, status.

## Quality test
If the solution could be written before the data was inspected, the diagnosis is probably too shallow.
