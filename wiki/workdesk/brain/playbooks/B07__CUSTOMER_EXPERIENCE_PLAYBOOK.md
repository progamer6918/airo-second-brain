# Customer Experience Playbook

## Goal
Move from satisfaction to loyalty to advocacy.

## Read the journey
Aware -> Appeal -> Ask -> Act -> Advocate.

## Read the need
Stated -> Real -> Unstated -> Delight -> Secret, plus the Job To Be Done.

## Experience standard
CASH: Convenience, Action, Speed, Hassle Free.

## Delight levers
Joy, Pride, Connection.

## Measure
- CSAT for satisfaction.
- NPS for advocacy propensity.
- retention/repeat/referral behavior for actual relationship outcome.

## Organization
If the issue crosses sales/service/marketing, use shared feedback and coordinated problem solving; do not trap it inside one department.
