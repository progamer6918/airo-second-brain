# Weekly Market Info → Performance Diagnosis

Use this when the Owner asks whether a local market event explains retail/M/S movement.

## Sequence
1. **Resolve period and geography** — dealer + kecamatan + event dates.
2. **Retrieve event evidence** — category + detailed narrative; do not rely on label alone.
3. **Retrieve performance** — retail/M/S/segment for the same or appropriately lagged period.
4. **Check denominator and competitor movement** for M/S.
5. **Check alternative mechanisms** — stock, pricing/MSW/FID/BA, activity, competitor, territory, seasonality.
6. **Assess timing** — event must precede/coincide plausibly with performance movement.
7. **Classify claim** — observation, correlation, hypothesis, or supported mechanism.
8. **PICA only after localization/root-cause evidence**.

## Guardrails
- Never infer causality from one market-info entry.
- Same event can be reported by multiple dealers in the same kecamatan; preserve dealer POV.
- If actual weekly Market Info submissions are not supplied, state that the operating process is known but event history is unavailable.
- Do not expose portal credentials or access URLs.
