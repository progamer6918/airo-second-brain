# Method Selection - DMAIC, PICA, PDCA, Design Thinking

ASSDP Advance explicitly permits multiple project methods. WorkDesk should choose method based on the problem, not force every task into one template.

| Method | Best fit | Core question |
|---|---|---|
| PICA | Operational performance gap requiring decomposition/corrective action | Where is the problem, why, and what corrective action? |
| PDCA | Recurring execution / continuous improvement | Did the plan work and what should be standardized/corrected? |
| DMAIC | Quantified improvement project with baseline, root cause and control | Can we define, measure, analyze, improve and control the gap? |
| Design Thinking | Customer problem/solution uncertainty | What does the user actually need and what solution works? |
| 8 Step | Allowed by Advance project guidance; exact source-specific steps not reconstructed in Batch08 | Use only when a trusted 8-Step reference is available. |

## Combination rule

Methods can nest:
- Design Thinking to discover human need;
- DMAIC/PICA to diagnose measured operational gap;
- PDCA to run and improve ongoing execution.

Do not claim “method complete” when its source-specific process has not yet been reconstructed.
