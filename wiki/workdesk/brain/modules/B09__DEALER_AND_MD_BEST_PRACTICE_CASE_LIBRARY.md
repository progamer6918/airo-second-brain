# Dealer & Main Dealer Best-Practice Case Library

Batch09 adds four historical cases with different unit of analysis:

- **AUM dealer transformation:** structural dealer turnaround across people, governance, assets, technology, activity and stakeholder collaboration.
- **Bali MD strategy:** local market sensing -> 4P -> weekly area/dealer control -> network readiness -> activity portfolio.
- **LOL CRM:** lead-capacity allocation -> profiling -> follow-up skill -> daily monitoring -> booster -> evaluation.
- **Area SPV practice:** planning/execution/monitoring/evaluation plus tactical/strategic/relational dealer partnership.

These are not templates to copy literally. They are case patterns used to generate hypotheses and implementation options, after checking the current local facts.
