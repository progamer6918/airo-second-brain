# Fresh-AI Brain Bootstrap

Use this sequence for professional WorkDesk questions.

## 1. Classify the request
- **Professional work**: answer in normal professional language. Do not expose repo/session/governance ceremony.
- **ASB/repo/runtime maintenance**: use the Control Plane and canonical AIRO governance.

## 2. Resolve the professional domain
Use [[KNOWLEDGE_DISCOVERY]] or [[TASK_ROUTER_V2]]. Do not ask the user to know framework names.

## 3. Load shared reasoning controls
Always respect:
- [[reference/CANONICAL_DECISION_RULE_LIBRARY]]
- [[reference/SOURCE_AUTHORITY]]
- [[reference/CURRENTNESS_SUPERSESSION]]
- [[reference/CONTRADICTION_UNRESOLVED]]

Load [[reference/CANONICAL_FORMULA_LIBRARY]] when metrics/numbers are involved.

## 4. Load the relevant canonical domain dossier
The eight dossiers in `domains/` are the durable professional brain. They merge source-derived modules and cross-source reasoning rather than presenting 80 independent summaries.

## 5. Bring in Business Memory for real/current work
The professional brain explains **how to think**. Canonical `wiki/workdesk/business-memory/` and current operating data explain **what is actually happening**. Never substitute a historical training example for current business facts.

### Decision-grade current-state retrieval
For actual business-number questions, load `../business-memory/operational/CURRENT_OPERATING_STATE.md` first, then the relevant TSV for exact drill-down. For commercial/MSW questions use `../business-memory/commercial/MSW_CURRENTNESS_RETRIEVAL.md` + version resolver + applicable offer rows. Do not answer a current-number question from training/framework memory when structured current-state memory exists. For current Integrated TTM/POS questions, also load `../business-memory/operational/INTEGRATED_TTM_POS_CURRENT_STATE_2026-08-11.md` and distinguish current meeting guidance from unproven submission state. For Market Info Tools/current weekly field-sensing questions, load `../business-memory/operational/MARKET_INFO_TOOLS_CURRENT_STATE_2026-08-11.md`; distinguish the transitional MD Google Form validation gate from the intended future direct-portal flow, and never expose portal credentials/URLs.


## 6. Apply currentness before using dated claims
Resolve requested date → applicable authority → revision/supersession → conflict state. Historical examples are usable as pattern/case memory, not silent current rules.

## 7. Separate evidence from inference
State whether a claim is:
- source/business-memory fact;
- calculation from supplied facts;
- diagnostic inference/hypothesis;
- illustrative scenario.

Never present an illustrative action impact as a forecast without a model/evidence.

## 8. Escalate to source memory only when needed
For exact slide/sheet logic, source conflict, detailed provenance, or a detail not retained in the canonical dossier, use `source-memory/` and the source-level fidelity audit. Original source remains ultimate evidence authority.

## 9. Never repair source gaps silently
If current authority is absent, a formula is unresolved, or the source conflicts with itself, say so. `UNRESOLVED` is better than invented certainty.
