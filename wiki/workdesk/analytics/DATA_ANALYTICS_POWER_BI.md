# Data Analytics & Power BI

## 🍼 10 detik

Analytics mengubah data menjadi keputusan. Power BI adalah salah satu alat kerja Owner; kualitas dashboard bergantung pada definisi KPI, data model dan validation—bukan visual saja.

## Analytics ladder

Useful working progression:

- descriptive — what happened;
- diagnostic — why;
- predictive — what may happen;
- prescriptive — what should be done.

## Project discipline from training notes

The Data Analytics note describes use-case discovery/prioritization and project artifacts such as Project Charter, WBS, schedule and roadmap. Because this note comes from recording/AI cleanup, use it as supplementary learning context unless corroborated by original training material.

## Power BI project note

Owner note describes a sales dashboard concept by type/dealer: data collection → cleaning/transformation → metrics → Power BI views/filter/drill-through → refresh/monitoring.

## WorkDesk default QA

Before visualization:

1. define KPI and grain;
2. validate source completeness/duplicates/types;
3. reconcile targets/actual/time scope;
4. model dealer/product/period consistently;
5. test totals against trusted source;
6. only then design visual/drill paths.
