# Wiki Sources

Direktori ini berisi catatan sumber (source notes) yang disadur secara aman dari dokumen eksternal atau log.

## Aturan
- Catatan sumber adalah hasil saduran (sanitized).
- Sumber mentah yang bersifat privat/sensitif dilarang masuk ke public ASB.
- Metadata checksum, path, dan commit harus dipelihara.
- Catatan sumber tidak dianggap sebagai bukti sah kecuali dokumen aslinya ada.
