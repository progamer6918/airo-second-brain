# Web Clips Registry

Direktori ini digunakan untuk menyimpan catatan hasil kliping web (web clips) yang diimpor dari sistem Windows melalui repositori transisi `AIRO_CLIP_INBOX`.

Semua berkas di sini bersifat derivatif dan mematuhi tata kelola AIRO Second Brain.
